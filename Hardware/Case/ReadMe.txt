3D Printing Notes

When printing buttons, print a few at a time, such as all 4, at least.  On my H2S Bambu Lab printer, if printing only 1, it prints too fast and the tip is warped.  Printing 2 or more at once fixes this issue.

Screws need to be self-tapping plastic or wood (not sheet metal).
The screws inside the case should be M2.5 x 8mm.
The screws for outside of the case should be M2.5 x 15mm.

Light pipes can be purchased from Amazon for example, 3mm acrylic.  There is a model you can 3D print for cutting them to size with a Dremel tool for example.  One side is the shorter WiFi pipe length (only 1 is needed), while the other side is for the LED size, 8 are needed.
